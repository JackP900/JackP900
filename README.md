# Hi, I'm Jack 👋
 
I'm a Computer Science student at Northumbria University (Year 1), based in the North East of England. I build projects in Python and JavaScript, work through structured self-study, and contribute to Northumbria Formula Student as part of the Chassis & Suspension group.
 
## 🔧 What I'm working on
 
- **PitView** is a real-time motorsport telemetry dashboard built with Python, Flask, SQLite and Arduino. It reads brake, throttle and steering from physical sensors (a load cell, a hall sensor and an AS5600 magnetic encoder) and streams them to a live browser dashboard over Server-Sent Events at 1 to 8 ms latency. I tripled its end-to-end throughput from 162 to 476 readings/sec, and it has a test suite running in CI.
- **F1 Race Strategy Simulator** is a Python pipeline using the FastF1 API to pull Formula 1 telemetry and visualise tyre strategies, lap times and pit stop performance across race events.
